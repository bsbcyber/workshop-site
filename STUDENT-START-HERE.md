# Student Start Here — Workshop 1

## Goal

Build a personal portfolio website, manage it in GitHub, and publish it using GitHub Pages. You do not need to be an experienced programmer. Start with the provided template and make focused changes.

## Bring

- A laptop and reliable internet access
- A GitHub account you can sign into
- Visual Studio Code and Git
- Access to your GitHub Copilot student license, if activated

## The workflow

1. Choose Editorial, Developer, or Professional.
2. Create your own repository from the instructor-provided starter.
3. Open the project in VS Code and inspect the files.
4. Personalize your resume and ask Copilot for one targeted improvement.
5. Create an issue with acceptance criteria.
6. Create a branch, commit your change, push it, and open a pull request.
7. Review the diff and acceptance criteria. Merge when ready.
8. Publish with GitHub Pages and verify the live URL.

## If you arrive late

Ask the facilitator which checkpoint is current. Start from the repository-ready or personalized-site checkpoint instead of repeating the entire session. Complete the remaining tasks with the class.

## Copilot prompt pattern

State the context, desired outcome, constraints, and what evidence should show the task is done. Ask Copilot to explain a proposed change and review the diff before accepting it.

## Safety

Don't paste passwords, API tokens, private keys, or sensitive personal details into prompts or source files. Treat AI-generated code as a proposed change that you remain responsible for reviewing.

## Completion checklist

- [ ] My repository exists and I can open it in VS Code.
- [ ] My site contains personalized content.
- [ ] I made a descriptive commit.
- [ ] I used an issue, branch, and pull request to review a change.
- [ ] My site is deployed and I have its URL.
- [ ] I can explain one Git concept and one Copilot change I reviewed.
